═══ DELIVERABLES ═══
Create entities under backend/src/<module>/entities/. Every entity uses @PrimaryGeneratedColumn('uuid'), @CreateDateColumn({type:'timestamptz'}), @UpdateDateColumn({type:'timestamptz'}).

ENTITY 1 — User (table `users`)
  email varchar UNIQUE NOT NULL
  passwordHash varchar NOT NULL
  displayName varchar NOT NULL

ENTITY 2 — Project (table `projects`)
  ownerId uuid FK → users.id (onDelete: 'CASCADE')
  name varchar(80) NOT NULL
  url varchar NOT NULL
  targetUsername varchar NOT NULL
  targetPasswordEncrypted text NOT NULL  -- AES-GCM ciphertext, base64
  description varchar(500) NULLABLE
  status enum('created'|'crawling'|'crawled'|'failed') DEFAULT 'created'
  Index on (ownerId, updatedAt DESC) for the project list page.

ENTITY 3 — CrawlRun (table `crawl_runs`)
  projectId uuid FK → projects.id (CASCADE)
  status enum('queued'|'running'|'success'|'failed')
  startedAt timestamptz
  finishedAt timestamptz NULLABLE
  errorMessage text NULLABLE
  scriptPath varchar       -- path to generated crawl.ts
  rawDataPath varchar      -- path to raw JSON output
  Index on (projectId, startedAt DESC).

ENTITY 4 — UiNode (table `ui_nodes`)
  projectId uuid FK
  crawlRunId uuid FK
  url varchar NOT NULL
  title varchar
  parentNodeId uuid NULLABLE (self-fk)
  metadata jsonb           -- forms, buttons, anchors, screenshotPath
  UNIQUE (crawlRunId, url).

ENTITY 5 — UiEdge (table `ui_edges`)
  crawlRunId uuid FK
  fromNodeId uuid FK → ui_nodes.id
  toNodeId uuid FK → ui_nodes.id
  triggerLabel varchar     -- e.g. "Click 'Login'"
  metadata jsonb

ENTITY 6 — GeneratedTestCasePrompt (table `generated_test_case_prompts`)
  projectId uuid FK
  promptText text NOT NULL
  generatedResult text NULLABLE
  createdAt timestamptz

═══ CRYPTO (common/utils/crypto.util.ts) ═══
AES-256-GCM. Key from PROJECT_SECRET_KEY env (32 bytes base64). IV 12 bytes, auth tag 16 bytes. Output format: base64(iv ‖ ciphertext ‖ authTag).
Export encryptSecret(plain:string):string and decryptSecret(payload:string):string.
RULE: decryptSecret is called ONLY inside crawler.service.ts. Projects service NEVER decrypts. Plaintext passwords NEVER appear in any HTTP response, log, or error message.

═══ CRAWLER (Phase 5b) ═══
POST /api/projects/:id/crawl flow:
  1. 409 if a queued/running run already exists for this project.
  2. Insert CrawlRun {status:'queued'}; set Project.status='crawling'.
  3. Validate URL: parse, ensure http/https, axios.head with maxRedirects:5 timeout 5s, accept 2xx/3xx, reject 4xx/5xx as InvalidTargetUrlError.
  4. Decrypt target password.
  5. Render Handlebars template (define inline string in template-renderer.ts) with {url, username, password, maxDepth, maxPages, timeoutMs, outputJsonPath} → write to storage/projects/<projectId>/crawl-<runId>.ts.
  6. spawn('node', ['-r','ts-node/register', scriptPath]) with VERIFAI_OUTPUT_JSON in env. Pipe stdout/stderr to storage/projects/<projectId>/logs/run-<runId>.log.
  7. On exit 0: read raw JSON, transform via raw-transformer (one UiNode per unique url, edges per discovered nav trigger), persist in a transaction, set CrawlRun.status='success', Project.status='crawled'.
  8. On non-zero / exception: CrawlRun.status='failed', errorMessage, Project.status='failed'.

CRAWL SCRIPT (rendered .ts) must:
- Use Playwright Chromium headless.
- Login heuristic: page.fill('input[type=email], input[name*=user i], input[name*=email i]', username); page.fill('input[type=password]', password); click closest submit.
- BFS same-origin links up to MAX_DEPTH=3 / MAX_PAGES=50.
- Per page capture: final URL, <title>, forms (action/method/input names), buttons text, anchors {href,text}, screenshot at storage/projects/<projectId>/screenshots/<sha1(url)>.png.
- Write consolidated raw JSON at process.env.VERIFAI_OUTPUT_JSON. Exit 0 success / 1 error.

GET /api/projects/:id/crawls → list past runs.
GET /api/projects/:id/crawls/:runId → single run status.
GET /api/projects/:id/graph?runId? → {nodes, edges} for latest successful run (or specified).
  Node shape: {id, label, url, metadata, kind:'entry'|'internal'|'failed'} (entry = first crawled URL, failed = unreachable).
  Edge shape: {id, from, to, label}.
GET /api/projects/:id/screenshots/:hash → static file serving for the drawer thumbnails.
